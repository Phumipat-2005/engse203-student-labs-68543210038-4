## ครั้งที่ 1

**ถามอะไร**
* การออกแบบฐานข้อมูลแบบแยก 2 ตาราง (`users` และ `requests`), ไวยากรณ์คำสั่ง SQL พื้นฐานใน `queries.sql` (ข้อ 1–8 และ Challenge), การแก้ไข Error ขณะรันคำสั่ง `INSERT INTO` ใน SQLite รวมถึงการทดสอบ Database Constraints ทั้ง 5 ข้อใน CP25

**AI ตอบว่าอย่างไร (สรุปสั้น)**
* แนะนำการใช้ Foreign Key เชื่อมความสัมพันธ์แบบ 1:N, แก้ไขความเข้าใจเรื่องการรันคำสั่ง SQL ที่ต้องรันในไวยากรณ์ SQL แท้ไม่ใช่คำสั่ง Shell, แนะนำชุดคำสั่งค้นหาข้อมูล (`JOIN`, `WHERE`, `ORDER BY`, `LIKE`, `DISTINCT`) และแนวทางการทดสอบเพื่อดู Error จากการละเมิดข้อกำหนด (FOREIGN KEY, CHECK, UNIQUE, NOT NULL)

**ใช้ส่วนไหน / แก้เองตรงไหน**
* นำคำสั่ง SQL มาทดสอบรันจริงใน `campus.db` จนมีข้อมูลครบ 8 แถว, ตรวจสอบผลลัพธ์ผ่าน `check-week09.mjs`, และเรียบเรียงเอกสารอธิบายการออกแบบใน `DATA_MODEL.md` รวมถึงบันทึกผล Error ใน `CONSTRAINT_TEST.md` ด้วยตนเอง

**เข้าใจโค้ดที่ได้มาไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## สรุป

- เข้าใจหลักการออกแบบ Relational Database และประโยชน์ของการแยกตารางเพื่อลด Data Redundancy และแก้ปัญหา Update Anomaly
- เข้าใจและเขียนคำสั่ง SQL พื้นฐานร่วมกับการใช้ `JOIN` ได้อย่างถูกต้อง
- เข้าใจความสำคัญของ Database Constraints ในฐานะด่านป้องกันความถูกต้องของข้อมูลชั้นสุดท้าย
