# AI_USAGE — LAB 06

บันทึกการใช้ AI ระหว่างทำงาน · **ใช้ AI ได้ แต่ต้องเป็นเจ้าของโค้ดที่ส่ง**

> ผู้สอนจะสุ่มถามจากโค้ดที่ส่ง — ถ้าอธิบายไม่ได้ คะแนนส่วนนั้นจะถูกทบทวน

---

## ครั้งที่ 1

**ถามอะไร**
* สอบถามเรื่องแท็บ Body $\rightarrow$ raw $\rightarrow$ JSON อยู่ตรงไหนในโค้ด และทำไมยิง Postman แล้วยังได้ 404 ทั้งที่ใส่ข้อมูลใน raw แล้ว  

**AI ตอบว่าอย่างไร (สรุปสั้น)**
* อธิบายว่าแท็บดังกล่าวอยู่ในโปรแกรม Postman ไม่ใช่โค้ดเซิร์ฟเวอร์ และที่ติด 404 เพราะยังตั้ง Method เป็น GET และระบุ URL ผิดเส้นทาง (/api/unknown-path) ต้องแก้เป็น POST ไปที่ /api/requests  

**ใช้ส่วนไหน / แก้เองตรงไหน**
* ปรับการตั้งค่า HTTP Method และระบุ URL ปลายทางใน Postman ด้วยตนเอง  

**เข้าใจโค้ดที่ได้มาไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## ครั้งที่ 2

**ถามอะไร**
* ถามสาเหตุที่ Postman แจ้งเตือน Error ว่าประเภทคำร้องไม่ถูกต้อง และความเร่งด่วนต้องเป็น normal หรือ urgent ทั้งที่คิดว่าส่งข้อมูลตรงแล้ว พร้อมนำโค้ด validateRequest.js มาตรวจสอบ  

**AI ตอบว่าอย่างไร (สรุปสั้น)**
* ชี้จุดผิดพลาด 2 จุดใน JSON คือ การระบุ requestType เกินเป็น "แจ้งซ่อมครุภัณฑ์" (ในระบบมีแค่ "แจ้งซ่อม") และการตั้งชื่อคีย์ผิดเป็น urgency แทนคำว่า priority ตามที่ Middleware กำหนด  

**ใช้ส่วนไหน / แก้เองตรงไหน**
* แก้ไขชื่อคีย์และค่าข้อมูลในแท็บ raw JSON ของ Postman ให้ตรงกับ Whitelist ใน validateRequest.js  

**เข้าใจโค้ดที่ได้มาไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## ครั้งที่ 4

**ใช้ส่วนไหน / แก้เองตรงไหน**
