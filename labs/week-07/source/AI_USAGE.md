บันทึกการใช้ AI ระหว่างทำงาน · **ใช้ AI ได้ แต่ต้องเป็นเจ้าของโค้ดที่ส่ง**

> ผู้สอนจะสุ่มถามจากโค้ดที่ส่ง — ถ้าอธิบายไม่ได้ คะแนนส่วนนั้นจะถูกทบทวน

## ครั้งที่ 1

**ถามอะไร**
* ปัญหา CORS Error ใน CP09–CP10 ทำไมฝั่ง Console ขึ้น Error แต่คำขอยังไปถึงเซิร์ฟเวอร์ และหลักการ 4 คำถามท้ายบท (Same-Origin Policy, ลำดับของ cors middleware, การรักษา signature ใน service layer และพฤติกรรมการโยน error ของ fetch)

**AI ตอบว่าอย่างไร (สรุปสั้น)**
* อธิบายว่า CORS เป็นกลไกความปลอดภัยของเบราว์เซอร์ไม่ใช่เซิร์ฟเวอร์, สาเหตุที่ `app.use(cors())` ต้องอยู่บนสุดเพื่อดัก Preflight (`OPTIONS`), Service Layer ช่วยแยก UI ออกจากการต่อ API โดยคง signature เดิม, และ `fetch` จะโยน error เฉพาะตอน Network พังเท่านั้น

**ใช้ส่วนไหน / แก้เองตรงไหน**
* นำหลักการมาใช้ตอบคำถามความเข้าใจ และเขียนโค้ดเปิด `cors({ origin: config.corsOrigin })` ใน `api/src/app.js` ด้วยตนเอง

**เข้าใจโค้ดที่ได้มาไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ
